How to download the source code and install software/packages and run the program locally
Software you want to have installed on your device is Node.js version 18 or higher and run it using npm. 
Make sure git is downloaded and we used visual studio code as out editor 
To download the source code make sure your repository points to product and clone it 

git clone https://github.com/your-username/product.git
cd product

you can also download a zip and extract is as well make sure it points to product 
Then install any directories npm install
